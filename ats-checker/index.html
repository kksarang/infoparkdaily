How to read this score

This is not Naukri, Zoho Recruit or any employer’s ATS. It approximates the first text pass: can software read the file, and do keywords overlap if you pasted a job.

Fix missing contact and headings first. Add a missing skill only when it is true. A high score is not a shortlist.
