# InfoparkDaily hiring hub

The `/infoparkdaily/` section is an **employer-only** hiring hub linked from the main site’s **About Us → InfoparkDaily**. Job seekers use the main `/jobs/` board and Career Tools.

## Public pages

- Home (HR / talent acquisition landing), talent directory (`/workers/`), about/how it works, contact.
- `/infoparkdaily/jobs/` redirects to the main `/jobs/` board.
- Market snapshot stats on the home page reuse curated counts from `data/jobs-data.js`.
- Approved community talent profiles come from Firestore.
- Public HTML is generated by `npm run build:community`.

## Member workflows

Firebase Authentication reuses the Career Tools project. Email verification is required before writing account records.

- New accounts are **employer** accounts (company name required).
- Employer job submission → admin review → public community job post.
- Employer invitation → hire request → admin approval → private chat.
- Seeker flows (browse/apply/saved jobs / worker profile editor) are removed from this hub.

## Administration

`/infoparkdaily/admin/` checks a server-managed `marketAdmins/{verified-email}` registry. The authorised administrator is **enitexaai@gmail.com**.

## Local development

Visit `/infoparkdaily/` on your local static server after `npm run build:community`.
