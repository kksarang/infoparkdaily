Roadmap

What you’ll learn

Follow the modules in order. Finish a small project at the end of each one.

  1. 01

    Linux & networking

    3 weeks
    • Shell commands and permissions
    • Processes and services
    • DNS, HTTP, ports
    • Bash scripting
  2. 02

    CI/CD

    3 weeks
    • Git workflows
    • GitHub Actions or Jenkins
    • Automated tests in pipelines
    • Artifacts and releases
  3. 03

    Containers

    4 weeks
    • Docker images and compose
    • Kubernetes pods, deployments, services
    • Config and secrets
    • Scaling and health checks
  4. 04

    Cloud

    4 weeks
    • Compute, storage, networking on AWS or Azure
    • IAM and security
    • Infrastructure as Code (Terraform)
    • Monitoring and alerts
