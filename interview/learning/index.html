  3. OOP and Git
  4. SQL and one database
  5. One framework (Spring Boot, Django, React, Node.js)
  6. Build and deploy 2–3 projects

Communication skills

Speak clearly, write professionally

Communication is assessed in every round — not just HR.

Self-introduction

Practise a 60–90 second intro: present → past → proof → future. Record it and listen once.

Spoken English

Read aloud 10 minutes daily, watch tech talks with subtitles, and answer one interview question aloud every day.

Professional email

Short, specific, polite. Use the templates in the Email guide.

Explaining technical work

Use problem → approach → result. Avoid jargon unless asked; draw simple diagrams.

Listening

Pause before answering, repeat the question if unsure, and ask clarifying questions.

Body language

Sit upright, look at the camera on video calls, smile, and avoid reading from notes.
