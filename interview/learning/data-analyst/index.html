Roadmap

What you’ll learn

Follow the modules in order. Finish a small project at the end of each one.

  1. 01

    Excel for analysis

    2 weeks
    • Formulas, lookups (XLOOKUP)
    • Pivot tables and charts
    • Data cleaning
    • Conditional formatting
  2. 02

    SQL

    3 weeks
    • SELECT, WHERE, ORDER BY
    • JOINs and GROUP BY
    • Subqueries
    • Window functions
  3. 03

    Power BI / Tableau

    3 weeks
    • Importing and modelling data
    • DAX measures
    • Interactive dashboards
    • Publishing and sharing
  4. 04

    Statistics & storytelling

    2 weeks
    • Mean, median, distributions
    • Correlation vs causation
    • Choosing the right chart
    • Presenting insights
