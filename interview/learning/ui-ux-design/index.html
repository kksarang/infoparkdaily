Roadmap

What you’ll learn

Follow the modules in order. Finish a small project at the end of each one.

  1. 01

    Design basics

    3 weeks
    • Layout, spacing and alignment
    • Typography
    • Colour and contrast
    • Visual hierarchy
  2. 02

    UX process

    3 weeks
    • User research and personas
    • User flows
    • Wireframes
    • Usability testing
  3. 03

    Figma

    3 weeks
    • Components and auto layout
    • Prototyping
    • Design systems
    • Hand-off to developers
  4. 04

    Portfolio

    2 weeks
    • Writing case studies
    • Showing process, not just screens
    • Presenting your work
    • Accessibility checks
