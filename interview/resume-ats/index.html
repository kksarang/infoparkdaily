Writing bullets that work

✗ Responsible for API development.

✓ Built 14 REST APIs in Spring Boot for a payments module, cutting response time from 900 ms to 250 ms.

✗ Did a project on library management.

✓ Built a library management app (PHP, MySQL) with search and fines; tested 40 cases; used by 200 students.

Tip

Formula: action verb + what you did + tools + result (number).

ATS guide

How applicant tracking systems read your resume

An ATS collects applications, parses your resume into fields, applies eligibility questions and lets recruiters search by keyword. A human usually makes the final decision.

  1. Upload
  2. Parse into fields
  3. Knock-out questions
  4. Keyword search / ranking
  5. Recruiter review
ATS do and avoid
DoAvoid
One column, standard fontsText boxes, tables for layout, multiple columns
Standard headings: Summary, Skills, Experience, Projects, EducationCreative headings like “My Journey”
Exact JD keywords you genuinely haveKeyword stuffing or hidden white text
Text-based PDF (or DOCX if asked)Scanned PDF, image resume, password-protected file
Dates like Jan 2025 – Mar 2026Only years or mixed formats
Reality check

An ATS checker — including InfoparkDaily’s — is a preparation tool. It is not the employer’s system, and a high score doesn’t guarantee shortlisting.

Resume optimisation

Optimise for each job in 10 minutes

  1. Copy the JD’s must-have skills into a list.
  2. Tick the ones you genuinely have; add any missing ones to your Skills section and a relevant bullet.
  3. Rewrite your summary to name the target role.
  4. Move the most relevant project or achievement to the top.
  5. Run the resume and JD through the ATS checker.
  6. Export a text PDF named Firstname_Lastname_Role_Resume.pdf.
