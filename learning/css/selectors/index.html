Selectors

Element, class, id, descendant and pseudo-class selectors.

← CSS introduction Colours, fonts & units →
  • p — every <p>.
  • .card — elements with class="card" (reusable).
  • #top — the element with id="top" (unique).
  • nav a — links inside nav (descendant).
  • a:hover, input:focus, li:first-child — pseudo-classes for state and position.
  • h1, h2 — group selectors with a comma.

Prefer classes for styling. They are reusable and keep specificity low.

Key points

            
  • . for class, # for id.
  • Space = descendant.
  • Pseudo-classes target states like :hover.

Interview corner

            
How is specificity calculated?
Roughly: inline styles > ids > classes/attributes/pseudo-classes > elements. More specific selectors win regardless of order.

            
Why avoid styling with ids?
Ids have high specificity, making styles hard to override and not reusable.
