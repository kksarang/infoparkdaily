Lists

Unordered, ordered and description lists.

← PreviousImages Next lesson →Tables

<ul> makes a bulleted list, <ol> a numbered list. Each item is an <li>. Lists can be nested by putting a new list inside an <li>.

Ordered lists accept start="5", reversed and type="a" / "I".

A description list (<dl>) pairs terms (<dt>) with descriptions (<dd>) — useful for glossaries and key/value details.

Key points

            
  • <ul> bullets, <ol> numbers, <li> items.
  • Nest a list inside an <li>.
  • <dl> for term/description pairs.

Practice task

            
Make an ordered list of your daily study plan with a nested unordered list of topics under one item.

            
          

          

            
Interview corner

            
When would you use a description list?
For name–value pairs such as a glossary, FAQ or job details (Location: Kochi, Experience: 2 years).

            
Can you put block elements inside <li>?
Yes — list items can contain paragraphs, headings, other lists and more.
