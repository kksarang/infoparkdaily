SELECT & WHERE

Choosing columns and filtering rows with WHERE, AND, OR, IN, BETWEEN and LIKE.

← SQL introduction ORDER BY, LIMIT & DISTINCT →

List the columns you need instead of * — it's faster and clearer. Rename a column in the output with AS.

WHERE keeps only rows that match a condition:

  • Comparison: = <> < > <= >=
  • Combine: AND, OR, NOT (use brackets to be clear)
  • city IN ('Kochi', 'Kozhikode') — matches any value in a list
  • salary_lpa BETWEEN 5 AND 8 — inclusive range
  • title LIKE '%Developer%' — pattern: % any text, _ one character
  • company_id IS NULL — missing values (never = NULL)

Key points

  • Select only the columns you need.
  • Text values go in single quotes.
  • Use IS NULL, not = NULL.

Quick check

Which pattern matches titles that start with 'Data'?

'Data%' means 'Data' followed by anything.

Practice task

List the title and salary of jobs whose title contains 'Developer' and pay between 5 and 8 LPA.

Interview corner

Why does WHERE column = NULL return nothing?

NULL means unknown, and any comparison with unknown is unknown (not true). Use IS NULL or IS NOT NULL.

What is the difference between WHERE and HAVING?

WHERE filters individual rows before grouping; HAVING filters groups after GROUP BY, so it can use aggregates like COUNT(*).
