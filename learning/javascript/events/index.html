Events

addEventListener, click and input events, forms.

← PreviousThe DOM You finished JavaScript →Explore all learning

Events let code react to the user: click, input, submit, keydown, change.

button.addEventListener("click", () => {
  …
});
  • The handler receives an event object — event.target is the element.
  • event.preventDefault() stops default behaviour such as a form reload.
  • Prefer addEventListener over inline onclick="" attributes.

Key points

            
  • addEventListener(type, handler).
  • event.target is the element.
  • preventDefault stops form reloads.

          

          

            
Quick check

            
Which call stops a form from reloading the page on submit?

            

              
              
              
              
            

            
            

            
preventDefault cancels the browser's default action for that event.

          

          

            
Practice task

            
Build a character counter: as the user types in a textarea, show how many characters are left out of 200.

            
          

          

            
Interview corner

            
What is event delegation?
Attach one listener to a parent and use event.target to handle events from many children — efficient and works for elements added later.

            
What is event bubbling?
An event fires on the target first and then moves up through its ancestors. stopPropagation() stops it.
