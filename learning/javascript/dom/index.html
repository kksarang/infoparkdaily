The DOM

Selecting elements and changing text, classes and styles.

← Arrays & objects Events →

The DOM (Document Object Model) is the browser's live version of your HTML that JavaScript can read and change.

  • Select: document.querySelector(".card") (first match), querySelectorAll (all).
  • Change text: el.textContent = "…" (safe — never inserts HTML).
  • Classes: el.classList.add / remove / toggle("active").
  • Create: document.createElement("li") then list.append(li).

Prefer textContent over innerHTML for user input — innerHTML can run injected code.

Try it yourself


              

            

            
Edit the code and press Run (or Ctrl/⌘ + Enter). Code runs only in your browser, in a sandbox.

          

          

            
Key points

            
  • querySelector uses CSS selectors.
  • textContent is safe for text.
  • classList toggles styles cleanly.
