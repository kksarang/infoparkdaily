Variables & data types

let, const, strings, numbers, booleans, null and undefined.

← PreviousJavaScript introduction Next lesson →Operators & conditions

Variables store values. Use const by default and let when the value will change. Avoid the old var.

  • String — text: "Kochi", or a template literal: `Hi ${name}`.
  • Number — 42, 3.14.
  • Boolean — true / false.
  • undefined — declared but not set; null — deliberately empty.
  • Objects and arrays — covered later.

typeof tells you a value's type.

Key points

            
  • const by default, let if it changes.
  • Template literals use backticks and ${}.
  • typeof shows the type.

          

          

            
Quick check

            
Which keyword declares a variable that cannot be reassigned?

            

              
              
              
              
            

            
            

            
const bindings cannot be reassigned after they are declared.

          

          

            
Practice task

            
Store a job title, salary and remote flag in variables and print one sentence about the job using a template literal.

            
          

          

            
Interview corner

            
var vs let vs const?
var is function-scoped and hoisted (avoid it). let and const are block-scoped; const can't be reassigned (but objects it points to can still change).

            
null vs undefined?
undefined means a value was never assigned; null is an intentional 'no value'.
