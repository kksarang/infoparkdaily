Power BI introduction

What Power BI is, Desktop vs Service, and the get data → model → visualise → share workflow.

← Back toPower BI home Next lesson →Cleaning data with Power Query

Power BI is Microsoft's business intelligence tool for turning data into interactive reports and dashboards. It's one of the most requested skills for data analyst, MIS and business analyst jobs.

  • Power BI Desktop (free, Windows) — where you build reports.
  • Power BI Service (online) — where reports are published, shared and refreshed on a schedule.
  • Power BI Mobile — viewing reports on phones.

The workflow

  1. Get data — Excel, CSV, SQL databases, SharePoint, web APIs.
  2. Transform — clean it in Power Query.
  3. Model — relate tables and write DAX measures.
  4. Visualise — build report pages with charts, cards and slicers.
  5. Share — publish to the Service and set up refresh.

Key points

  • Power BI turns data into interactive reports.
  • Build in Desktop; share through the Service.
  • Workflow: get data → transform → model → visualise → share.
  • Analyst and MIS job posts often ask for it.

Quick check

Where do you usually build a Power BI report?

Reports are designed in Power BI Desktop and then published to the Power BI Service for sharing.

Practice task

Install Power BI Desktop, recreate the sample table in Excel, load it and build a card for total Amount and a bar chart of Amount by Product.

Interview corner

What is Power BI and what are its main components?

A Microsoft BI tool for connecting to data, modelling it and building interactive reports. Main parts: Power BI Desktop (build), Power Query (transform), the data model with DAX (calculations), Power BI Service (publish, share, refresh) and mobile apps.

What is the difference between a report and a dashboard in Power BI?

A report has one or more interactive pages built from a single dataset. A dashboard is a single page in the Service made of tiles pinned from one or more reports, used for a high-level overview.
